# Pre-Reuse Audit — Remediation Plan (2026-09-18)

A full review before treating this repo as a reusable foundation found
gaps (things a consuming app or a real deployment would hit) and
over-engineering (machinery that cost more to maintain than it protects).
The developer chose to fix all of it, in phases, one PR each. Mark a phase
done here when its PR merges.

| Phase | Scope | Status |
|---|---|---|
| A — Registry consumer gaps | `@storybook/addon-docs` missing from `starter`; consumers never type-check `tests/`/`e2e/` (`tsconfig.test.json` unreferenced); shipped `AGENTS.md` carries foundation-only phase rules and claims hooks that don't exist; `deps-allowlist.json` duplicates/stale entries. Prove with a full dogfood (not `--install-only`), tag. **Also found:** `starter` installed `conventions`/`theme` from `main` regardless of ref; upstream `use-mobile.ts` fails lint. | Done — #18, `v1.8.0` |
| B — Auth robustness | Logout/login don't clear the query cache (cross-user cache leak); a mid-session 401 doesn't return to `/login`; login doesn't return to the original page; a network failure on `/auth/me` reads as logged out. | Done — #20, `v1.9.0` |
| C — Backend correctness and deploy safety | `Widget.available_from` uses SQLModel's tz-naive mapping (same bug class as Phase 10's `Session.expires_at`) — add a widget POST/PATCH to `check-phase-8.sh`, then fix; PBKDF2 blocks the event loop; seeded dev user with a published password; `COOKIE_SECURE` default. Write a deployment checklist. **Also found:** a plain `npm run build` ships the MSW mocks (`VITE_API` is build-time). | Done — #21 (backend only, not tagged) |
| D — Consumer lifecycle docs + data-table behavior | Document the upgrade path (re-adding `starter` overwrites consumer-owned files) and how a new app gets the backend; table state in the URL, debounced search, clamp page after delete, `aria-sort`; `AppError` 403/409 (deferred — nothing returns them). | In progress |
| E — Pruning | One source for the entity playbook; archive `BUILD-PLAN.md` + retired `check-phase-*.sh` behind a short `ARCHITECTURE.md`; drop the `openapi.yaml` sha256 freeze; narrow Storybook visual tests to patched primitives and out of `starter`; delete merged branches; doc drift (`STATUS.md` latest tag, etc.). | Not started |

Order matters only loosely: A first (it produces a verified release to
build on), E last (it moves files the others touch).
